Working Principle of Finite Automata

A Finite Automaton is a mathematical model used to recognize patterns in input strings. It consists of states, an alphabet, transition functions, a start state and final states.

1. Password Verification

The password validator checks whether the password contains at least one uppercase letter, one lowercase letter, one digit and one special character. The password length must be between 8 and 16 characters, and spaces are not allowed.

2. Email Format Validation

The email validator checks a practical email format consisting of a local part, an @ symbol, a domain name and a final extension containing at least two letters.

3. ATM PIN Verification

The ATM PIN validator accepts exactly four numeric digits. Each digit moves the automaton to its next state. After four digits, the automaton reaches its accepting state.

Limitations of Finite Automata

  • Finite automata have a limited number of states.
  • They cannot remember unlimited amounts of information.
  • They cannot validate every possible real-world email rule.
  • Password validation checks format, not password strength against attacks.
  • ATM PIN validation checks the number format, not the actual PIN stored by a bank.

Conclusion

This project demonstrates how finite automata can be applied to practical input validation problems. DFA-based validators provide a systematic way to accept valid strings and reject invalid strings based on predefined rules.
